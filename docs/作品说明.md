# 学事通 · CampusPedia —— 作品说明

## 一、作品简介

学事通（CampusPedia）是一款面向高校学生的**校园事务智能问答系统**。将学校公开制度文档（学籍管理、奖惩处分、奖助学金、宿舍管理、素质拓展学分、就业、医保等）导入后，基于「混合检索 + 重排序 + 大模型」技术，为学生提供**流式问答、答案溯源引用、检索过程可视化**的一站式咨询体验，替代"翻多套系统、反复问群"的低效信息获取方式。

## 二、解决的问题

1. 校园制度信息分散在教务处、学生处、就业处等多个官网，检索成本高；
2. 通用大模型不掌握学校内部制度，答非所问或胡编乱造；
3. 学生咨询的答案需要**可溯源**（引用到具体文件条款），而非"听起来像"。

## 三、核心功能

- **流式问答**：SSE 逐字输出，边生成边展示；
- **答案溯源**：结论后标注 [来源N]，可点击跳转官网原文条款；
- **混合检索**：向量检索(pgvector) + 关键词检索(MySQL 全文 ngram) + RRF 融合；
- **重排序 + 阈值过滤**：qwen3.7-text-rerank 精排，低相关片段自动丢弃；
- **Query 改写 + 多轮记忆**：结合上下文把续问改写成完整检索问题；
- **思考过程可视化**：展示改写 query、候选条数、保留条数、阈值；
- **三级权限**：游客（临时会话不落库）/ 普通用户（会话持久化、刷新不丢）/ 管理员（语料管理 + 参数配置 + 数据大屏）；
- **多格式语料导入**：md / txt / pdf / doc / docx，法规类文档按"条款"智能切分；
- **管理后台**：语料上传与向量化、RAG 参数在线调优、ECharts 数据大屏。

## 四、技术架构

- 前端：Vue 3 + TypeScript + Vite + Element Plus + Pinia + ECharts
- 后端：Java 17 + Spring Boot 4.1 + MyBatis-Plus + Spring Security + JWT
- 生成：DeepSeek deepseek-chat（SSE 流式）
- 向量化：DashScope qwen3.7-text-embedding-flash（1024 维，可降级 hash）
- 重排：DashScope qwen3.7-text-rerank
- 存储：pgvector（向量）+ MySQL 8（元数据/全文）+ Redis 7（缓存）
- 容器化：Docker Compose 三容器一键启动

**RAG 流水线**：文档上传 → 文本提取 → 递归切分 → 向量化入库 →（提问时）Query 改写 → 混合检索 → Rerank 精排 → 阈值过滤 → Prompt 组装 → 流式生成 → 溯源标注 → 会话落库。

## 五、创新点与亮点

1. **混合检索 + RRF + Rerank + 阈值过滤**的完整检索增强链路，兼顾召回与精度；
2. **意图控制**：法规类文档按"条款"粒度切分，检索结果直接命中具体条目，溯源准确；
3. **可解释性**：思考过程与参考来源可视化，让用户"看得见"答案怎么来的；
4. **权限分级**：游客/用户/管理员三级，兼顾易用与数据管理；
5. **健壮性**：embedding/rerank 均可优雅降级，缺密钥也能离线运行。

## 六、工程与可复现性

- 完整 git 提交历史（每个功能一个 commit，中文 + 英文前缀），全程可追溯；
- Docker Compose 一键拉起三容器，10 分钟可复现；
- 建表脚本 + 配置模板齐全，密钥走 gitignore 的 local 配置，不泄露；
- 前端/后端分层清晰，RAG 各环节独立成类，便于替换与评测。

## 七、演示要点（5-8 分钟建议）

1. 打开首页，问「转专业需要什么条件？」→ 流式输出 + 溯源引用 + 思考过程；
2. 追问「那能转几次？」→ 展示多轮上下文理解；
3. 展示来源卡片点击跳转官网原文；
4. 游客模式 → 注册登录 → 会话列表（刷新不丢）；
5. 管理员登录 → 上传一份 PDF/制度文件 → 向量化 → 再提问命中新文档；
6. 管理后台数据大屏 + RAG 参数在线调优。
