## ② 功能演示（0:30-3:30）

### 镜头 1：登录（0:30-0:50）
- 演示学号 + 密码登录（注册也可提一句）。
**台词**："用学号和密码登录，登录后问答记录会持久化保存。"

### 镜头 2：问答 + 溯源（0:50-2:00）⭐核心
- 输入"国家奖学金怎么申请？"
- 展示**流式打字机输出** + 答案末尾 **[来源1]** 标注。
- **点击 [来源1]**，展示命中的具体文件条款（可溯源）。
**台词**："注意它是逐字流式输出的，而且每个结论都标注了 [来源N]，点开就能看到它到底引用了哪份文件的哪一条——这是和普通大模型最大的区别，它只依据学校真实资料回答，不瞎编。"

### 镜头 3：多轮追问（2:00-2:30）
- 追问"那成绩要排前多少名？"（不重提奖学金）
**台词**："我再追问一句，注意我没有重复'国家奖学金'，它自己结合上文理解了我在问什么——这是多轮 Query 改写。"

### 镜头 4：会话历史 + 个人中心（2:30-3:30）
- 展示左侧会话列表（重命名/删除）、刷新不丢；
- 个人中心改资料/头像/密码。
**台词**："历史会话都在这，刷新也不会丢。个人中心可以改资料、换头像、改密码。"

**台词**："后台有数据大屏可视化，RAG 参数也能在线热更新，不用重启。"

## ④ AI 协同过程复现（5:00-7:00）⭐必须 ≥2 分钟

**台词开场**："这个项目 90% 的代码是 AI 生成的，下面我用 2 分钟复现一下我是怎么和 AI 协同的。"

### 复现示例 A：Prompt 驱动生成核心模块
- 展示一条 Prompt（真实可复现），例如：
  > "请用 Spring Boot 实现一个混合检索器：pgvector 向量检索 + MySQL 全文检索，用 RRF 融合两路得分，返回带文档元数据的检索结果。要求：检索失败要 try-catch 兜底，不要影响主流程。"
- 展示 AI 生成的代码片段（HybridRetriever.java）。
**台词**："这是我当时给 AI 的核心 Prompt——把两路检索用 RRF 融合。AI 生成了代码骨架，我又强调了'失败要兜底'这个工程约束。"

### 复现示例 B：引导 AI 修一个 Bug
- 展示一段真实 Bug 的修复 Prompt，例如：
  > "流式问答结束后，前端不会自动停止，一直转圈。我发现是后端 saveMessage 在 emitter.complete() 之前执行导致的阻塞。请把落库移到 complete 之后。"
- 展示修复后的代码 diff。
**台词**："这是当时一个顽固 Bug——生成完了不停止。我先定位到是落库阻塞了流，再用这条 Prompt 让 AI 把落库移到 complete 之后，问题解决。"

### 复现示例 C：意图控制 Prompt
- 展示系统提示词的迭代（从"结论后标[1][2]"到"仅首次引用标注一次"）。
**台词**："引用标注怎么展示，我也是用 Prompt 精确约束的——让它只在首次引用处标一次，不要每句话都重复。"
